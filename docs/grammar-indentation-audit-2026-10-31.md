# Grammar indentation audit, 2026-10-31

Reviewed all 78 active language packages and their 119 Tree-sitter grammar descriptors. Runtime rules improved in 58 packages; four further packages gained regression coverage for deliberately unchanged behavior. The policy is conservative: explicit delimiters and parsed suite headers can add indentation; ambiguous expressions retain the inherited margin. Explicit reindent preserves whitespace inside multiline literals, raw text and comments. Typing keeps manual indentation unless a clear closing token or branch provides a correction.

The implementation uses Lumine's existing indentation resolver. A relative paste that needs no indentation shift now retains its original hard tabs and whitespace-only rows, even when the language has syntax indentation rules. The [authoring policy](tree-sitter-grammars.md#conservative-indentation) explains row-based captures and the distinction between typing, relative paste adjustment and explicit reindent. JavaScript and TypeScript keep optional braceless-condition, logical-operator and ternary-operator indentation available, with those guesses disabled by default.

Reference behavior was checked against [Neovim's indentation vocabulary](https://github.com/nvim-treesitter/nvim-treesitter/blob/master/CONTRIBUTING.md#indents), its [language queries](https://github.com/nvim-treesitter/nvim-treesitter/tree/master/queries), and [Zed's indentation contract](https://zed.dev/docs/extensions/languages#auto-indentation). These use different algorithms; the rules here were authored for Lumine and verified against each package's committed parser. Parser sources, Wasm binaries, inherited notices and registry dependency versions are unchanged.

## Verification

The 78 full package suites pass 1778 specs with no failures, each in its own isolated Electron process with local CI mode unset. Package regressions cover Enter, incomplete headers, one-line constructs, typed closing tokens, branch alignment, literal/comment contents and explicit reindent where applicable. Changed packages pass ESLint and packaging checks, with indentation queries, specs and applicable license files present in their tarballs. Repository formatting checks distinguish committed UTF-8/LF source from local CRLF checkout conversion.

The editor's focused validation passes 268 specs, including compilation of every declared query in all 119 workspace grammar descriptors and the 43 bundled descriptors, plus paste checks for inline and worker syntax. All 429 Node Tree-sitter runtime and syntax-worker tests pass, including indentation cancellation, streaming and typing filters. The fleet's 108 Wasm assets pass ABI and pinned-build-tool validation. Full package suite counts and source revisions appear below; focused tests overlap those suites and are not added again.
