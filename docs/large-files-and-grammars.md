# Large files and grammars

Lumine checks file opening and automatic grammar loading separately. Both limits default to 40 MB. `core.warnOnLargeFileLimit` asks before opening a text file at or above that size. Cancelling leaves that file unopened. After opening is accepted, `core.grammarLoadLimit` selects **None** for a file at or above its limit, without constructing a Tree-sitter parser or sending its contents to the syntax worker. The settings remain independent and measure a megabyte as 1,048,576 bytes; setting the grammar limit to `0` disables automatic grammar suppression.

The warning's **Enable Grammar** button selects the detected grammar for that buffer. The grammar selector also offers **None**, **Auto Detect**, and **Plain Text**. None disables syntax analysis; Plain Text is a Tree-sitter grammar and can provide text syntax and embedded language features. Auto Detect explicitly returns to automatic language selection, including for the currently open large file.

None has its own settings scope, `.text.plain.null-grammar`. A `core.customFileTypes` entry keyed by `text.plain.null-grammar` can also associate file types with None when those files should normally open without syntax analysis.

An explicit grammar choice, including None, belongs to the buffer and applies to all its split views. Session restoration applies that choice before creating a parser. Closing the document removes its choice with the buffer; opening the file again evaluates the limits again. There is no separate remembered permission for a path. Newly loaded grammars and path changes do not replace an explicit None choice.

Document analysis packages skip None buffers, retire pending work, and clear their results when a document switches to None. Selecting a real grammar lets them resume. Basic text editing, saving, navigation, and file operations remain available. None reduces syntax and package analysis costs; the text buffer, rendering, explicitly requested text operations, and loading the file still require resources.

Package authors should compare `editor.getGrammar()` with `lumine.grammars.nullGrammar` before reading or processing document contents. Observe `editor.onDidChangeGrammar()` to release per-document observers, cancel requests and clear decorations when None is selected, and recreate them when a real grammar returns. Recheck the grammar after asynchronous operations before publishing results. Do not deactivate the package globally: other documents can continue using it. The null grammar sentinel is available through `nullGrammar` and `grammarForId("text.plain.null-grammar")`; `getGrammars()` continues to return Tree-sitter grammar instances only. Passing JavaScript `null` to `assignLanguageMode()` means Auto Detect, while the string `"text.plain.null-grammar"` selects None.
