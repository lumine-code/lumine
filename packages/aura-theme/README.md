# aura-theme

A modern, brighter day and deeper night take on the One UI and syntax themes.

## Features

- **One foundation**: loads the shared One UI and syntax styles before applying focused Aura overrides.
- **Clear contrast**: uses brighter day surfaces and deeper night surfaces while keeping text comfortable.
- **Soft geometry**: adds modest rounding to tabs, controls, selections, and overlays.
- **Quiet structure**: keeps consistent low-contrast separators while leaving list rows uncluttered.
- **Aura accent**: uses a clear blue accent across both appearance modes.

## Theme pack

The package declares `aura-day-ui`/`aura-day-syntax` and
`aura-night-ui`/`aura-night-syntax` as the **Aura** pack. Use
`theme-selector:toggle` to preview and select it.
