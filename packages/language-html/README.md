# language-html

HTML language support.

## Features

- **Grammars**: provides both Tree-sitter and TextMate grammars.
- **Syntax highlighting**: full grammar coverage for HTML files.
- **Snippets**: shortcuts for common tags and document scaffolding.
- **Code folding**: collapse elements and comments.
- **Comment toggling**: block comment support.

## Services

- **[hyperlink.injection](https://lumine-code.github.io/docs.html#services/hyperlink.injection)** (`^1.0.0`): consumed to highlight URLs inside markup as clickable links.
- **[todo.injection](https://lumine-code.github.io/docs.html#services/todo.injection)** (`^1.0.0`): consumed to highlight `TODO`-style markers inside comments.
